ふたり分担 PWA

1. ZIPを展開してください。
2. index.html / manifest.webmanifest / sw.js / icon画像を同じフォルダに置いたまま、GitHub Pagesへアップロードしてください。
3. HTTPSの公開URLをスマホで開くと、対応ブラウザではインストール案内が表示されます。

注意：現版のデータは各端末のlocalStorageに保存されます。ゆた・かほ間の自動同期はまだありません。
